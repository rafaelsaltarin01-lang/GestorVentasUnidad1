# Sistema Gestor de Ventas e Inventario Express (Mini-POS)

**Estudiante:** Rafael Saltarin  
**Institución:** Corporación Universitaria Americana  

## Descripción del Proyecto
Prototipo de aplicación de consola desarrollado en C# (.NET 8) que automatiza las operaciones esenciales de un punto de venta y control de inventario local. Permite administrar productos con validaciones estrictas, procesar compras aplicando descuentos e IVA (19%), y generar reportes financieros de caja en tiempo real utilizando exclusivamente colecciones dinámicas y métodos estáticos.

## Instrucciones para Clonar y Ejecutar

1. Asegúrate de tener instalado **.NET 8 SDK** en tu equipo.
2. Abre tu terminal y clona o ubícate en la carpeta del repositorio.
3. Ejecuta el siguiente comando para iniciar la aplicación:
   ```bash
   dotnet run
